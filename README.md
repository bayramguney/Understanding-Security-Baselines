# Key Concepts Learned

## Security Baselines

A security baseline is a minimum set of security configurations that all systems should follow.

Benefits include:

- Consistent security
- Reduced attack surface
- Easier auditing
- Faster compliance
- Standardized system configuration

---

## SANS Security Policies

SANS provides free policy templates that organizations can customize for:

- Acceptable Use
- Artificial Intelligence
- Software Development
- Incident Response
- Password Policies
- Remote Access
- Mobile Devices

---

## CIS Benchmarks

CIS Benchmarks are industry-recognized secure configuration guides.

They help organizations:

- Harden operating systems
- Secure applications
- Protect cloud environments
- Meet compliance requirements
- Reduce vulnerabilities

---

## NIST National Checklist Program

The NIST National Checklist Program provides:

- Secure configuration checklists
- SCAP-compatible benchmarks
- Government-approved security guidance
- Automated compliance validation

---

## SCAP

**Security Content Automation Protocol (SCAP)**

SCAP allows security tools to:

- Verify compliance
- Scan systems automatically
- Detect configuration weaknesses
- Validate security baselines

## ⭐ Key Takeaway
